# Support

GitHub issues are for bug reports, regressions and feature proposals — please don't use them to ask questions.

- 💬 Questions: ask on [StackOverflow with the `i18next` tag](https://stackoverflow.com/questions/tagged/i18next)
- 🌍 Looking for a localization management platform by the i18next maintainers? [Locize](https://www.locize.com)
