# Security Policy

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

Email **support@locize.com** ([Locize](https://www.locize.com) is the company of the i18next maintainers) — vulnerability reports are treated with priority.

Where enabled, you can also use GitHub's private vulnerability reporting: open the **Security** tab of the affected repository and click **Report a vulnerability**.

Please include:

- a description of the issue and its impact
- steps to reproduce or a proof of concept
- affected package(s) and version(s)

If not AI slop or spam, you will normally receive a first response within a few business days. Please give us a reasonable amount of time to release a fix before any public disclosure.

## Supported Versions

Security fixes are applied to the latest major version of each package.
